# Simple-Sum-Calculator-
This project was created as part of my learning journey in Python. It demonstrates fundamental programming concepts such as:

- User input
- Data type conversion
- Variables
- Basic arithmetic operations
- String formatting

## 💻 How It Works

The program:
1. Asks the user to input two numbers
2. Converts the inputs to integers
3. Calculates the sum
4. Displays the result in a formatted message
